# Devpost Submission Plan

## Required submission assets

- functional application
- public or judge-accessible URL
- testing instructions
- public YouTube or Vimeo demo under three minutes
- project description
- CALL-E account email
- required pull-request URL to the CALL-E public repository
- repository or code access as required by the rules

## Submission narrative structure

### Inspiration

Manual phone coordination is the missing execution layer in many field-service tools.

### What it does

Explain the closed-loop incident workflow and commitment ledger.

### How it was built

- Ionic Angular + Capacitor
- NestJS
- CALL-E
- PostgreSQL
- realtime events
- human approval policies
- audit and consent controls

### Challenges

- reliable asynchronous phone workflow state
- structured outcome validation
- safe authorization and disclosure
- responsive command-centre design
- real-call demo safety

### Accomplishments

- actual phone call
- branching no-answer path
- structured ETA and cost extraction
- human approval
- dispatch and verification
- complete dark/light responsive product

### What was learned

Focus on how phone agents need application state, policy, human control and operational feedback loops.

### What is next

- multilingual calls
- technician companion
- deeper property integrations
- predictive vendor selection
- production compliance controls

## Judge testing instructions

Provide:

- judge URL
- judge username/password
- safe scenario name
- exact steps
- which call is real versus simulated
- approved test number behavior
- reset instructions
- expected result
- support contact

## Demo-video structure

- 0:00–0:15 problem and outcome hook
- 0:15–0:35 create incident
- 0:35–1:10 real CALL-E workflow
- 1:10–1:35 structured vendor comparison
- 1:35–1:55 human approval and dispatch
- 1:55–2:20 commitment timeline and resolution
- 2:20–2:40 audit, consent and production readiness
- 2:40–2:55 impact metrics and closing statement

## Submission quality gate

- no unfinished labels
- no broken public links
- video audio is clear
- text is readable at normal playback
- claims match the functioning application
- test credentials confirmed in a clean browser
- environment remains available throughout judging
